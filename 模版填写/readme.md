# Word文档模板填写技能 使用说明书
## 1. 功能概述
**文档模版填写**是基于MCP协议开发的Word自动生成技能，内置PCL采购相关标准化Word模板；用户通过自然语言描述需求，Agent自动匹配模板、提取业务字段、渲染生成Word文档，并返回外网直链供下载。
服务部署于内部集群，支持多套标准文档一键生成。
